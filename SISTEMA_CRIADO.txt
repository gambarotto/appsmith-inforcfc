🚀 SCRIPTS CRIADOS
═══════════════════════════════════════════════════════════════════════════

1. start-appsmith-dev.sh (~350 linhas)
   • Verifica todas as dependências (Docker, Java, Node, Yarn)
   • Cria e configura MongoDB com replica set
   • Cria e configura Redis
   • Define todas as variáveis de ambiente
   • Inicia Backend (Spring Boot) em background
   • Inicia RTS (Runtime Service) em background
   • Inicia Frontend (React) com hot-reload
   • Configura proxy Nginx via Docker
   • Salva PIDs para gerenciamento
   • Mostra status colorido e informativo

2. stop-appsmith-dev.sh (~170 linhas)
   • Para todos os processos via PID salvos
   • Libera portas se necessário
   • Para containers Docker (nginx)
   • Pergunta sobre MongoDB/Redis (preserva dados)
   • Limpa arquivos temporários
   • Interface amigável com confirmações

3. status-appsmith-dev.sh (~230 linhas)
   • Verifica status de containers Docker
   • Verifica portas abertas (6 serviços)
   • Testa endpoints HTTP (3 APIs)
   • Mostra tamanho dos logs
   • Indica localização dos dados
   • Resumo visual com cores
   • Comandos úteis ao final

4. test-appsmith-dev.sh (~200 linhas)
   • Suite completa de testes automatizados
   • Testa containers Docker (3 testes)
   • Testa conectividade (6 portas)
   • Testa APIs e JSON (6 testes)
   • Valida estrutura de arquivos (6 testes)
   • Total: ~20 testes automatizados
   • Relatório final com score e dicas
